Natural Language Processing Across Turkic Languages

Methods and Applications

How to build and evaluate language technology for a family whose languages share much of their grammar but differ widely in data, tools and benchmarks. The book focuses on what is specific to Turkic: agglutinative morphology and vowel harmony, three major scripts, transfer between related languages, and building corpora, treebanks and benchmarks where few exist.

Three recurring questions

How does morphology affect a task? What changes when the script changes? Which knowledge transfers between related languages? Every chapter returns to them.

🧪

Linguistics plus practice

Each chapter pairs linguistic analysis with a hands-on section, most built on TurkicNLP 0.5.0. Exercises range from Unicode case-folding to training and evaluating models.

🎓

Who it's for

NLP researchers and practitioners, graduate students, and members of Turkic language communities. The code assumes intermediate Python and basic machine learning. Linguistic concepts are introduced as needed.

📚

Companion texts

General NLP is covered briefly, with Jurafsky & Martin's Speech and Language Processing as the companion. Johanson's Turkic is the linguistic reference throughout.

Built with the toolkit

Run every practical yourself

The practical sections use TurkicNLP: transliteration in Chapter 3, Apertium transducers in Chapter 6, neural analysers and the morpheme tokenizer in Chapter 7, UD parsing in Chapter 8, tagging and NER (including the LLM backend) in Chapter 9, NLLB in Chapter 10 and Omnilingual ASR in Chapter 11. Install it once and follow along.

Explore the toolkit → Appendix B: tools
$ pip install "turkicnlp[all]"
import turkicnlp

nlp = turkicnlp.Pipeline("kaz")
doc = nlp("Мен мектепке бардым.")
print(doc.to_conllu())
